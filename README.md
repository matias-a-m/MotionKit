# MotionKit

**Animaciones nativas, microinteracciones y feedback háptico coherente.**

`MotionKit` estructura cómo se anima e interactúa con una app. Integra transiciones suaves, gestos significativos y feedback háptico para mejorar la percepción del producto sin sacrificar rendimiento.

---

## Propósito

- Estandarizar animaciones y feedback.
- Mejorar la expresividad del sistema.
- Aumentar percepción de fluidez y respuesta.

---

## Contenido

- Animaciones base (`fadeIn`, `scaleIn`, `slide`).
- Feedback háptico (`success`, `warning`, `error`, `impact`).
- Coordinadores de transición.

---
